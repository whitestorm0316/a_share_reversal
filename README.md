# A股「缩量企稳反转」策略回测研究

一个从零构建的 A 股短线反转策略**实证检验**项目。包含数据抓取、事件驱动回测引擎、三轮参数实验、交互式回测台和一份完整研究报告。

> ### 一句话结论
> 核心前提「**下跌后连续缩量/地量 = 卖压衰竭**」被数据**证伪**，且方向是反的——缩量越严格，单笔净收益越差。
> 但原命题的另一半「**企稳后可买**」是**成立**的，是整个体系里唯一有真实贡献的成分。

## 1. 研究问题

待检验的交易假设原文：

> 股票下跌后出现连续缩量/地量，说明卖压可能衰竭；随后股价企稳，买入反弹。

项目要求**验证而非假定**该假设成立，并系统回答四类问题：

1. **哪个环节真正有效？** 把策略拆成「超跌 / 缩量 / 企稳」三个因子，逐一做消融实验，量化各自的边际贡献。
2. **参数怎么设？** 缩量定义（A–E）、企稳定义（A–E）、超跌分位区间（D1–D3 … D5–D8）、止损（固定 % / ATR 倍数）、止盈（+3% … +15% / 不设）、退出方式（6 种）逐项比较。
3. **固定止盈是否掐死大赢家？** 专章对比「固定 +6% 止盈」与「让利润奔跑」的右尾差异。
4. **在真实 A 股约束下还剩多少？** T+1、手续费、印花税、过户费、滑点、涨跌停不可成交、停牌、ST 剔除，全部纳入。

## 2. 核心结论（先看这里）

以**用户原始设定**（超跌 D2–D6 + 缩量 A + 企稳 A + 止损 -3% + 止盈 +6%）在全市场 2016-04 ～ 2026-09 上运行：

| 指标 | 数值 |
|---|---|
| 交易笔数 | **515,524** |
| 胜率 | 38.37% |
| 单笔平均净收益 | **-0.0202%** |
| t 值 | **-3.18** |

**这是一个统计上显著为负的期望值**（t = -3.18，p < 0.01）。样本量足够大，负号不是噪声。

### 2.1 缩量条件是负面因子（核心发现）

固定其余条件不变，只替换缩量定义（`results/e1_volume.csv`）：

| 缩量定义 | 单笔净收益 | t 值 | 样本数 |
|---|---|---|---|
| **不设缩量条件** | **+0.0782%** | +25.86 | 2,342,349 |
| A：两日递减 `VOL_t < VOL_{t-1} < VOL_{t-2}` | -0.0202% | -3.18 | 515,524 |
| B：近 5 日量连续下降 | -0.0983% | -6.01 | 77,181 |
| D：`VOL < VOL20×0.7` | -0.1740% | -32.78 | 715,937 |
| E：近 3 日均量 `< VOL20×0.6` | -0.2452% | -29.33 | 289,233 |
| C：**地量** `VOL < VOL20×0.5` | **-0.3045%** | **-31.74** | 217,908 |

**缩量越严格，收益越差，是一条单调规律。** 「地量」在 A 股更多反映**关注度流失**而非卖压衰竭——这是对原命题最直接的反驳。

### 2.2 2×2 因子分解（全报告最有说服力的一张表）

其余条件固定为「不创新低 + 收涨」，只开关「超跌」和「缩量A」（`results/f1_ablation.csv`）：

| | 无缩量 | 有缩量A | 缩量的边际贡献 |
|---|---|---|---|
| **无超跌** | +0.0061%（n=1,895,301） | +0.0558%（n=298,205） | +0.050pp |
| **有超跌** | +0.2511%（n=842,989） | +0.2521%（n=146,610） | **+0.001pp** |

- 超跌的边际贡献：**+0.245pp**（真实有效）
- 缩量的边际贡献：**+0.001pp**，统计上等于零，**却砍掉了 83% 的信号**

> 换句话说：**「缩量」这个条件既没有筛出更好的交易，也没有筛出更差的交易——它只是随机地删样本。**

### 2.3 企稳条件贡献最大

| 企稳定义 | 单笔净收益 | t 值 |
|---|---|---|
| **B：连续 2 日不创新低** | **+0.1553%** | +17.36 |
| E：收盘站上 MA5 | +0.1233% | +16.62 |
| D：低点≥前低 且 收阳 | +0.0798% | +9.29 |
| A：`收盘 ≥ 前收`（原始设定） | -0.0202% | -3.18 |
| C：5 日低点后 2 日未破 | -0.0147% | -2.64 |

关键：企稳必须是**持续性状态**（连续 2 日不创新低），单日事件（收盘≥前收）无效。

### 2.4 其他重要结论

- **越紧的止损/止盈越差**：止损 -2% 是灾难（-0.0927%），ATR×2 最好（+0.1884%）；止盈 +3% 最差（-0.2299%），**不设止盈最好（+0.3452%）**。
- **固定 +6% 止盈确实掐死大赢家**：净收益 ≥ +10% 的交易从 18,389 笔降到 3,536 笔；单笔最大收益从 **+543.1%** 压到 **+37.7%**。右尾被削平、左尾完整保留——这就是「胜率 38% 但期望为负」的几何原因。
- **MA5 / MA10 退出是负贡献**（-0.1193% / -0.1015%），MACD 死叉（+0.2835%）和不设止盈（+0.3452%）才是正的。
- **「反转策略只适合上涨趋势」是错的**：牛市 **-0.3835%**（最差），熊市 **+0.1730%**（最好），震荡 +0.0764%。
- **成本致命**：零滑点 +0.1800% → 5bp +0.0799% → 10bp **-0.0202%** → 20bp -0.2199% → 30bp -0.4193%。**原始策略的盈亏平衡滑点仅约 9bp**（单边滑点每增加 1bp，单笔净收益下降约 2bp——买卖各收一次）。

| 复权方式 | 腾讯 **后复权**（`hfq`） |
| 指数范围 | 2013-07-29 起 |

> **为什么用后复权而不是前复权？**
> 前复权以最新价为锚点向前调整，长期历史段的价格可能被压到极小甚至为负，会让百分比止损、涨跌幅等以价格为分母的计算严重失真。
> 后复权以最早价为锚点向后调整，价格序列恒为正，且任意两日之间的比例关系与真实持有收益率完全一致。**对收益率类策略，后复权是更安全的口径。**
> 引擎额外做了保护：入场前校验 `开盘价 > 0` 且 `前收盘 > 0`；涨跌停判定统一用「当日开盘 / 前收盘 − 1」的相对涨幅，不受复权系数影响。

## 6. 策略定义

### 6.1 缩量条件（`vol_cond`）

| 代号 | 定义 | 含义 |
|---|---|---|
| `A` | `VOL_t < VOL_{t-1} < VOL_{t-2}` | 两日递减（原始设定） |
| `B` | 近 5 日成交量连续下降（4 次比较） | 持续缩量 |
| `C` | `VOL < VOL20 × 0.5` | **地量** |
| `D` | `VOL < VOL20 × 0.7` | 温和缩量 |
| `E` | 近 3 日均量 `< VOL20 × 0.6` | 均量萎缩 |
| `NONE` | 恒真 | 不设缩量条件（对照组） |

### 6.2 企稳条件（`stab_cond`）

| 代号 | 定义 | 含义 |
|---|---|---|
| `A` | `Close_t ≥ Close_{t-1}` | 收盘不跌（原始设定） |
| `B` | `Low_t ≥ Low_{t-1}` 且 `Low_{t-1} ≥ Low_{t-2}` | **连续 2 日不创新低** |
| `C` | 过去 5 日最低点出现在前 3 日，之后 2 日未跌破 | 低点确认 |
| `D` | `Low_t ≥ Low_{t-1}` 且 `Close_t > Open_t` | 不创新低 + 收阳 |
| `E` | `Close_t > MA5` | 站上 MA5 |
| `NONE` | 恒真 | 不设企稳条件（对照组） |

### 6.3 超跌前置条件（`oversold_cond`）

按**当日全市场** `ret20`（20 日收益）横截面排名取十分位，**D1 = 最超跌**，D10 = 最强势。可选区间：

`D1-D3`、`D2-D6`（默认）、`D3-D7`、`D4-D8`、`D1-D6`、`D1-D10`、`D5-D8`

### 6.4 买入规则（`buy_rule`）

| 规则 | 组成 |
|---|---|
| `A` | 超跌 `&` 缩量 `&` 企稳（原始设定） |
| `B` | 超跌 `&` 缩量 `&` 连续 2 日不创新低 `&` 收盘 > 前收 |
| `C` | 超跌 `&` 缩量 `&` 连续 2 日不创新低 `&` 收盘 > MA5 |

### 6.5 退出方式（`exit_mode`）

| 常量 | 逻辑 |
|---|---|
| `fixed_tp` | 固定止盈（全仓），配 `tp` 使用 |
| `tp_half_ma5` | +X% 卖 50%，余下跌破 MA5 卖出 |
| `ma10` | 跌破 MA10 卖出 |
| `macd` | MACD 死叉卖出 |
| `ma5` | 跌破 MA5 卖出 |
| `hold` | 仅止损 + 最长持有 |

止损支持**固定百分比**（`sl_mode="fixed"`，配 `sl`）与**波动率自适应**（`sl_mode="atr"`，配 `atr_k`，基准为 ATR14）。所有模式下均受 `max_hold` 最长持有天数约束。

## 7. 交易约束与成本模型

### 无未来函数

- 信号在 **T 日收盘**产生，**仅使用 ≤ T 的数据**；
- **T+1 开盘**执行买入；
- 因 T+1 制度，最早 **T+2** 才能卖出。

### A 股真实约束（全部已实现）

| 约束 | 实现方式 |
|---|---|
| T+1 | 买入日不可卖出，最短持有 1 个交易日 |
| 一字涨停不可买入 | 开盘价 ≥ 昨收 ×(1+涨停幅) 时跳过信号 |
| 跌停不可卖出 | 跌停日顺延至下一可成交日 |
| 涨跌停幅度分板块 | 主板 10% / 创业板·科创板 20% / ST 5%（`LIM` 矩阵） |
| 停牌 | 无 K 线自然跳过，最长持有顺延 |
| 长停复牌跳空 | 买卖间隔 > 10 个自然日则丢弃该笔（避免复牌跳空虚增收益） |
| ST / 退市 | 全样本剔除（204 只 ST） |
| 北交所 | 剔除（数据源限制） |
| 样本末端 | 未平仓交易按 `min(T-1, entry+max_hold)` 强制平仓，越界保护 |

### 成本模型（`engine.py`）

```python
COMMISSION    = 0.00025   # 佣金，双边
TRANSFER_FEE  = 0.00001   # 过户费，双边
STAMP_AFTER   = 0.0005    # 印花税（仅卖出），2023-08-28 起
STAMP_BEFORE  = 0.0010    # 印花税（仅卖出），2023-08-28 前
STAMP_SWITCH  = "2023-08-28"
```

印花税按**每笔交易的实际卖出日期**判断适用税率，而非统一按当前税率——这是回测长周期时容易被忽略、且会系统性高估收益的细节。

滑点默认 **10bp（单边）**，可通过参数调整；净值曲线（`equity_curve`）把买入成本+滑点计入建仓日、卖出成本+印花税+滑点计入平仓日。

### 9.6 候选策略的稳健性

| 策略 | 全样本 | 样本内 16-20 | 样本外 21-26 |

三者 IS/OOS **符号一致、量级稳定**，且精简版显著性最高（t=49）、样本量最大（842,989 笔）。

**成本敏感度（`f3_cost.csv`，10bp 基准）**

| 单边滑点 | 规则B | 精简版 | 随机基准 |

### 9.7 净值曲线（`f8_curves.json`，含成本）

等权篮子口径，2016–2026 全样本：

| 策略 | 总收益 | CAGR | 最大回撤 | Sharpe |
|---|---|---|---|---|
| 规则B | +15.00% | 1.31% | -38.59% | 0.161 |
| 规则C | +24.14% | 2.03% | -33.83% | 0.208 |
| 精简版（无缩量） | -24.99% | -2.63% | -49.76% | -0.101 |
| 随机全市场基准 | -41.87% | -4.91% | -63.53% | -0.256 |

> ⚠️ **口径提醒**：净值曲线是「每日对所有在持标的等权求日收益后累乘」，**不是资金复利曲线**。当每日并发持仓数很大时（精简版日均约 2,000 只）篮子趋近全市场等权指数，因此其净值反而更差——虽其单笔平均收益（+0.2511%）与规则B（+0.2521%）几乎相同。**结论请以单笔口径为主，净值仅作相对参考。**

### 9.8 市场漂移基准（`f6_drift.csv`，零成本随机持有）

| 持有天数 | 平均收益 |
|---|---|
| 1 日 | +0.0150% |
| 5 日 | +0.1819% |
| 10 日 | +0.3741% |
| **20 日** | **+0.7584%** |

这是**最重要的基准**：随机买入并持有 20 日的零成本漂移就有 +0.76%。候选策略平均持有 6 日、单笔 +0.25%，折算每日约 +0.041%；而随机持 20 日的每日漂移约 +0.038%。

> **换言之，候选策略的每单位时间优势仅约 0.003%/日——绝大部分「收益」来自市场 beta 而非 alpha。**

## 10. 推荐参数配置

综合 19 组消融与三轮稳健性检验，**参数最稳、逻辑最简**的版本为（与研究报告第 15.1 节一致）：

```python
{
    "rng":        "D2-D6",    # 超跌：ret20 全市场十分位 D2-D6
    "vol":        "NONE",     # 不设成交量条件（缩量边际贡献 ≈ 0，却砍掉 83% 样本）
    "stab":       "B",        # 连续 2 日不创新低
    "buy_rule":   "B",        # 或 C（收盘站上 MA5），二者等价性很高
    "sl_mode":    "atr",
    "atr_k":      1.5,        # 或 sl_mode="fixed", sl=0.05
    "tp":         None,       # 不设固定止盈（或放宽到 +15%）
    "exit_mode":  "ma10",     # 或 "macd"；不推荐 ma5（负贡献）
    "max_hold":   20,
    "slippage":   0.001,      # 10bp；保守压力测试请用 0.002
}
```

> **实现细节**：`buy_rule` 为 `"B"` 或 `"C"` 时，`stab` 参数**会被忽略**——因为这两条规则内部已硬编码了「连续 2 日不创新低」条件。`stab` 仅在 `buy_rule="A"` 时生效。

**实测表现（全样本 2016-04 ～ 2026-09，全市场）**

| 指标 | 数值 |
|---|---|
| 样本数 | 842,989 笔（是含缩量版的 **5.7 倍**） |
| 单笔净收益 | **+0.2511%**，t = **+49.31** |
| 胜率 | 41.3% |
| 平均持有 | 6.0 个交易日 |
| 样本内 2016-2020 | +0.1624%（t = +19.46） |
| 样本外 2021-2026 | +0.2940%（t = +45.65） |
| 滑点 20bp | +0.0508%（优势缩水约 80%） |
| 滑点 30bp | -0.1491%（转负） |
| 牛市条件 | -0.3401%（**显著为负，应停用**） |
| 熊市条件 | +0.3002%（最佳环境） |

**为什么「不设缩量」反而是推荐版本？** 因为缩量的边际贡献是 +0.001pp（统计上为零），却把样本从 842,989 笔砍到 146,610 笔。**在等价的期望收益下，保留 5.7 倍样本量能显著降低估计误差**——这正是精简版 t 值（49.3）远高于规则B（21.1）的原因。这是「奥卡姆剃刀」在量化研究里的量化体现：一个不带来收益、只带来样本损失和复杂度上升的条件，必须删掉。

### ⚠️ 但仍然不建议实盘

三个理由：

1. **单位时间优势极薄**：候选策略日均优势 ≈ +0.041%，而随机持有 20 日的市场漂移 ≈ +0.038%。**优势几乎被 beta 吃掉。**
2. **滑点脆弱**：20bp 滑点时优势从 +0.2511% 缩到 +0.0508%（缩水 80%），30bp 转负。超跌小市值股的真实冲击成本大概率超过 20bp。
3. **绝对收益太低**：净值 CAGR 仅 1.3%–2.0%，最大回撤 34%–39%。风险收益比不具吸引力。

> **本项目的价值在于量化地判断出一个投资直觉「哪一部分对、哪一部分错」，而不在于提供一个可盈利的策略。**

**判对的部分**：超跌 + 企稳（持续性）确实是有效的候选池过滤器。
**判错的部分**：缩量/地量不是卖压衰竭信号，反而是关注度流失的负面标志。

## 14. 已知局限

研究报告第 17 节列出了 6 条局限，此处补充关键的几条：

1. **多重检验偏差（最需警惕）**：整个项目隐含测试了上万个参数组合，规则B/C 的 +0.25% 仍可能部分来自幸存者偏差。**未经独立样本外验证前不应视为已确立的 alpha。**
2. **未做市值分层**：超跌股天然偏小市值，未剥离市值因子暴露，无法区分 alpha 与 size premium。
3. **两种口径不等价**：单笔算术平均（+0.2511%）与每日等权篮子净值（-24.99%）在精简版上出现方向不一致，原因是后者受每日并发持仓数量影响极大。**报告中一律以单笔口径为主，净值曲线仅作相对参考。**
4. **冲击成本低估**：滑点按固定 bp 线性建模，未建立基于成交量的冲击成本模型。规模资金实际成本会显著更高。
5. **未考虑分红除权**：使用后复权价格，实际持有期间的分红税负未单独建模。
6. **未做涨跌停开板内的排队与部分成交建模**：一字板只做「不可成交」处理，未模拟封板打开后的部分成交。
7. **调仓假设偏乐观**：假设建仓日可按开盘价全额成交，未考虑单日资金容量约束。
8. **涨跌停幅度是静态值**：`universe.csv` 的 `limit` 列是**当前**涨跌停幅度（主板 10% / 创业板·科创板 20% / 北交所 30% / ST 5%），未按历史时点切换。例如创业板在 2020-08-24 注册制改革前为 10%，本引擎在早期区间对其仍按 20% 判定涨停——这会**略微高估**早期创业板标的的可成交率（即低估摩擦），方向上对结论偏乐观。
9. **样本内/外为时间切分，非独立数据**：2016-2020 与 2021-2026 两段共享同一批标的，无法完全排除「同一生存偏差在两段同时存在」的可能。
